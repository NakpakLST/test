# Облачный сборщик Ozoner

`collector.js` — шаблон для управляемого облачного браузера, а не автономная программа Node.js. Ему нужны доступные в браузерной сессии `ozonerTab` и `nodeRepl`. Передавать только реальные пары `{column, url}` из `test!C5:BD5`. Выполнять `collectBatch` последовательно, не более пяти элементов за вызов; сохранять результаты между вызовами. После остановки не запускать повторно обработанные колонки. При блокировке сайта прекратить работу. Транспортные ошибки разрешать отдельным ограниченным повтором, сохраняя исходные записи.

Сбор и запись 18.11.2026 выполнены: 54 цены, лист test, B14:BD14. Проверка чтением после записи совпала по всем 55 ячейкам. `journal.js` сохраняет входы и результаты, проверяет привязку к столбцам, отклоняет дубликаты и незавершённый набор, ограничивает повторы инфраструктурных ошибок и останавливается при проверке сайта. `run.json` и `batch-*.json` — журнал этого запуска. Результаты сохранялись после каждого пакета, не после каждой страницы.

Google Sheets и облачный браузер доступны через отдельные интерфейсы. В этом запуске передача списка и результатов между ними выполнялась оператором чата, с контрольной суммой списка и проверкой столбцов; это не автономная интеграция. Для последующего запуска необходимо снова прочитать таблицу, передать входы в браузерную сессию, сохранять ответы пакетов и перед записью заново проверить дату, свободную строку, формулы и отсутствие изменений URL. Не использовать этот журнал для повторной записи.

Полный автоматический запуск между сессиями, автоматический вызов повтора и сценарии out-of-stock/блокировки на реальных страницах не проверены. Файлы могут не сохраняться после пересоздания среды.
